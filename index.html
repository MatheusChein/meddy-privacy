Política de Privacidade do Meddy

Última atualização: 13 de novembro de 2026

Resumindo: o Meddy não coleta, não envia e não compartilha nenhum dado seu. Tudo o que você cadastra fica guardado só no seu aparelho.

Quem somos

O Meddy é um app para lembrar de tomar seus remédios, desenvolvido por Matheus Chein. Esta política vale para os apps do Meddy para Android e iOS.

Quais dados o app guarda

Para funcionar, o Meddy guarda no seu aparelho as informações que você mesmo cadastra:

  • o nome de cada remédio, os horários, a frequência e a duração do tratamento;
  • o registro das doses que você marcou como tomadas ou puladas, com a data e o horário.

Esses dados ficam em um banco de dados local, dentro do app. Eles não saem do seu aparelho e não são enviados para nenhum servidor. O Meddy não tem servidor, não tem cadastro e não pede login.

O que o app não faz

  • Não coleta dados pessoais, de localização, de contatos ou de uso.
  • Não usa ferramentas de análise, rastreamento ou anúncios.
  • Não compartilha nem vende dados para ninguém.
  • Não acessa a internet para funcionar.

Lembretes e permissões

Os lembretes são notificações locais, agendadas pelo próprio aparelho. Para isso, o app pode pedir permissão para enviar notificações e, no Android, para agendar alarmes no horário exato e reagendá-los quando o aparelho é reiniciado. Essas permissões servem só para avisar você na hora das doses.

Backup do sistema

Se o backup automático estiver ativado no seu aparelho (Backup do Google no Android ou backup do iCloud no iPhone), o sistema pode incluir os dados do Meddy na cópia de segurança da sua conta. Esse backup é feito pelo Google ou pela Apple, conforme as configurações e as políticas deles. O desenvolvedor do Meddy não tem acesso a essas cópias.

Como apagar seus dados

Você pode excluir remédios a qualquer momento dentro do app. Ao desinstalar o Meddy, todos os dados guardados no aparelho são apagados.

Crianças

O Meddy não é direcionado a crianças e não coleta dados de ninguém, incluindo crianças.

Mudanças nesta política

Se esta política mudar, a nova versão será publicada nesta página, com a data de atualização acima.
